lib9p `_native_body` rewrites canonical top-level cell to endpoint-global native cell. VIEW_WAIT becomes VIEW_POLL and may generate multiple native cells/poll-trail commands. Reclaim donor cell and response_hash become native donor cell/native response hash; RELEASE_CELL mirrors those same replacements in payload. Repeated VIEW_WAIT polls replace reclaim with their prior native response ACK. `_read_response` restores top-level guest cell and VIEW_POLL→VIEW_WAIT, preserving other bytes including verification. Frame cell/session/hash bind each translated leg separately. Allocation/ordinary payload is unchanged.

A signed host receipt binds native command_hash, response_hash (verification removed), native cell, endpoint and controller. Guest json.native_cell currently means its guest cell; that private annotation is not an authenticated native translation witness. C2 must preserve exact receipt bytes and refuse to assert source/event/floor authority. Missing C6 remains refusal.

(b) host-produced signed guest-original binding: host must receive authenticated complete guest original plus exact translation provenance from its enrolled supervisor/backend, verify transformation including reclaim/poll trail, then sign a separately negotiated response union binding both legs. A supplied guest hash alone is insufficient. Both require explicit versioned protocol design; do not alter closed 1.3 or re-sign/downgrade current receipts in C2.
